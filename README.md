# Swipe Rush

A fast-paced mobile arcade game built with Godot 4.3.

## 🎮 About

Swipe between lanes, dodge rooftop obstacles, and deliver packages before it's too late.

## ✨ Features

- 📱 Mobile touch controls
- 🖱️ Mouse controls for desktop testing
- ⌨️ Keyboard controls
- 🏙️ Procedural rooftop environment
- 📦 Package delivery gameplay
- 💥 Hit effects and camera shake
- 🏆 Score and combo system
- 📈 Increasing difficulty

## 🛠️ Built With

- Godot 4.3
- GDScript

## 🚧 Status

**Alpha 3 — In Development**

The game is currently being developed and tested.
